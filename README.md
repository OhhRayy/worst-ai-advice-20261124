## What it does

`main.py` writes one line of the worst possible advice an AI could give to `/output/entry.txt`. The program is deterministic (the same bytes on every run), uses no network, and needs no input.

The line:

> Based on your data, I recommend replacing sleep with light jogging. Your body will adapt in 3-5 business days.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
